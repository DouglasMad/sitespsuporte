# SP Suporte

Site estático em HTML, CSS e JavaScript, sem instalação ou compilação.

## Utilizar
Abra index.html no navegador.

## Enviar para o GitHub
Extraia este ZIP e envie index.html e README.md para a raiz do repositório. Não envie apenas o ZIP.

## Contacto
O formulário abre o WhatsApp +351 964 848 813 com a mensagem preenchida. O visitante precisa de confirmar o envio no WhatsApp.

## Publicação
O ficheiro index.html pode ser servido por qualquer hospedagem estática. A configuração do domínio spsuporte.pt é feita na hospedagem escolhida.
